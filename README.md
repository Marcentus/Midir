# Midir Damage Meter for NA

## Getting Started

### Install Npcap
https://npcap.com/dist/npcap-1.80.exe

![image](https://github.com/user-attachments/assets/33cd8f9a-5c2b-4780-834f-1b43b2a39a86)

### Exitlag Configuration

To use this damage meter with Exitlag, you must set your TCP tunnels to **1** in your Exitlag settings.

### Recommended Setup

It is highly recommended to use a network switch with port mirroring capabilities (affordable options are available on Amazon for around $20). Mirror your main PC's traffic to a second PC and run the damage meter on that second machine.
